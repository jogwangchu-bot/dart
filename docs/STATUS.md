# 개발·검증 상태

기록 시각: 2026-10-21T16:35:09+09:00

## 확인한 사실

- 게시 후 현재 실행 환경에서 DART_API_KEY 변수 존재 확인. 값은 출력·파일 저장하지 않음.
- Python 3.12.14/Linux에서 자동 테스트 87개 통과, 실패·오류·건너뜀 각각 0.
- 82개는 가짜 응답을 이용한 소프트웨어 테스트, 5개는 실제 공식 웹 목록에서 기록한 메타데이터의 오프라인 후보 선택 테스트. 실제 API/원문 검증과 다름.
- 원본 엑셀 390종목 모두 읽기, 중복 코드 0, 순번 1~390과 선행 0 보존. 미래 관리자 열은 평가용 목록에서 분리.
- 첫 5종목은 000140, 000390, 000890, 000970, 001360. 나머지 385종목도 NOT_RUN으로 추적.

## 실제 5종목 API 시도

- 고유번호 ZIP API corpCode.xml 단계에서 제한된 재시도 후 HTTP 502로 중단.
- 별도 진단에서 인증 유무에 관계없이 OpenDART API·개발 가이드 요청이 동일한 접속 중계 오류를 반환. 안전하게 추린 응답 헤더의 오류 분류는 upstream proxy failure.
- DART 열람 사이트와 PyPI는 HTTP 200. 사용자도 PC에서 OpenDART 사이트가 열린다고 확인. 클라우드 접속 경로의 문제로 조사됐으며 API 키 유효성은 아직 확인하지 못함.
- 실제 확보한 OpenDART 원문 0건. 시험 통과·수집 완료로 보고하지 않음. 키 재발급·중복 비밀정보를 요청하지 않음.

## 별도로 확보한 공식 목록 기준

- 공식 DART 회사별 검색에서 5종목의 2019-01-01~2019-09-17 접수 목록 응답을 조회·보존.
- 보해양조의 마감 전 정정 사업보고서, 한국주철관의 2019.03 사업보고서·2019.06 분기보고서 등 실제 예외 사례 확인.
- 범위·후보 접수번호·SHA256은 docs/WEB_REFERENCE.md와 logs/manual-five-stock-web-reference.json 참조. 이는 전체 역사 범위·API 페이지 완전성·원문 버전의 검증이 아님.

## PC 시험 인계

- run_pc_5_stocks.bat: 설치 → 자동 테스트 → 필요시 가려진 키 입력 → 최대 5종목만 수집. 설정을 수동으로 여러 번 변경하지 않도록 구성.
- 입력한 키는 PC 프로세스 환경변수에만 넣고 새로 만든 값은 종료 시 제거. 기존 사용자 환경변수는 유지. 키를 파일·진단 ZIP에 기록하지 않는 로직을 테스트.
- 기술 진단 ZIP logs/PC_5_stock_diagnostics.zip은 로그·상태 CSV만 포함. 관리자 캐시·원본 입력 엑셀·원문 ZIP 제외.
- PC 네트워크의 실제 API 시험, Windows .bat/비밀 입력 실행은 아직 검증 전. 사용자 PC 실행 후 결과를 받아 확인해야 함.

## 남은 검증

실제 원문 다운로드·해시·기업 신원·회계기간·정정 관계·당시 유효 버전·첨부 대조, 25종목 검증, 전체 390종목 처리, Claude Code 독립검수 미완료. 원문과 공식 기록에 연결된 검토 근거가 없으면 REVIEW_REQUIRED로 유지. 정확한 API 최초 제공일 및 1999-01-01 이전 범위는 미검증. 자동으로 웹 신원 조사나 부분 정정 원문 합성을 완료했다고 주장하지 않음.

소스·원본 입력·로그·테스트 결과는 클라우드 작업 공간에 보존. GitHub 배포 대상은 프로그램 소스·테스트·사용 안내이며, 원본 명세서·엑셀·API 키·실행 기록·관리자 캐시·기존 개발용 ZIP은 제외. 이전 PC 시험용 ZIP은 관리자 원본 엑셀을 포함한 개발용 프로그램이며 Claude 투자 평가용 자료팩이 아님. 클라우드 설정 게시와 키 변수 반영은 확인했으나 별도 새 작업에서 최신 변경 복원까지 확인한 것은 아님.
