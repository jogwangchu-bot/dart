# 실제 공식 열람 목록 대조 기준

OpenDART API 접속 중계가 HTTP 502로 막혀 있는 동안, 별도로 접근 가능한 공식 DART 회사별 검색 폼을 사용해 5종목의 **2019-01-01~2019-09-17 접수 목록**을 조회했습니다. 검색에서 최종보고서만으로 제한하지 않았으며 응답 원본 HTML과 SHA256을 `cache/manual_official_records/` 및 `logs/manual-five-stock-web-reference.json`에 보존했습니다.

이 조회는 API의 전체 기간·모든 페이지 수집이나 원문 다운로드가 아닙니다. 법인 동일성·정정 관계·역사적 원문 버전을 승인하지 않습니다. 코드의 후보 선택을 대조할 공개 접수기록입니다.

한국주철관(000970)은 12월 결산을 강제하면 잘못 고르는 실제 사례입니다. 보해양조(000890)는 정보마감 전 기재정정 사업보고서를 확인할 수 있는 사례입니다. 삼성제약(001360)의 2019.03 분기보고서 정정 접수는 20190520000217이며, 더 최근 기간인 2019.06 반기보고서 후보와 구분해야 합니다.

이 공개 목록의 제한된 메타데이터를 `tests/fixtures/public_dart_2019_candidates.json`에 저장해 네트워크 없는 후보 선택 회귀 테스트 5개에 사용했습니다. 나머지 자동 테스트는 가짜 응답을 사용합니다. 이 테스트들로 실제 API 인증·다운로드·PIT 검증이 통과했다고 주장하지 않습니다. 원문 및 전체 기간 목록을 확보한 뒤 이 후보와 차이가 나면 원인을 조사해야 합니다.
