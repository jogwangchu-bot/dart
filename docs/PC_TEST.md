# PC에서 5종목 시험하기

현재 클라우드는 `opendart.fss.or.kr`로 가는 접속 중계에서 HTTP 502가 발생합니다. 게시와 키 환경변수 반영은 확인했지만 실제 API 인증·다운로드는 확인하지 못했습니다. 클라우드 설정을 바꾸거나 키를 새로 발급받으라는 뜻이 아닙니다. PC에서는 사이트가 열린다고 사용자께서 확인해 주셨으므로 PC용 실행기를 제공합니다.

## 실행 순서

1. [GitHub 저장소](https://github.com/jogwangchu-bot/dart)에서 ZIP을 다운로드하고 **압축을 풉니다**. 압축된 상태에서 실행하지 않습니다.
2. 풀린 프로젝트의 `input` 폴더에 기존 원본 엑셀을 복사하고 파일명을 `universe.xlsx`로 바꿉니다. GitHub에는 원본 엑셀이 없습니다. 프로젝트 폴더에서 **`run_pc_5_stocks.bat`를 더블클릭**합니다. PC Codex로 작업할 경우에는 `docs/CODEX_HANDOFF.md`를 읽고 로컬 에이전트가 명령을 실행하게 할 수 있습니다.
3. 패키지 설치와 자동 테스트가 끝나면, PC에 `DART_API_KEY` 환경변수가 없는 경우 키 입력을 요청합니다. 받은 OpenDART 키를 그 창에 붙여 넣고 Enter를 누릅니다. **입력한 글자가 화면에 보이지 않는 것이 정상입니다.** 키는 채팅에 보내지 않습니다.
4. 원래 순서의 5종목만 조회합니다. 요청 간격과 전체 과거 목록 조회 때문에 몇 분 이상 걸릴 수 있습니다. 창을 닫지 않고 완료 메시지를 기다립니다. 25종목·390종목 전체를 자동 시작하지 않습니다.
5. 끝나면 생성된 **`logs/PC_5_stock_diagnostics.zip`**을 이 대화에 첨부합니다. 성공·실패 어느 경우든 이 파일로 다음 진단을 진행할 수 있습니다. 실제 API 요청 전 패키지 설치 자체가 실패해 ZIP이 없으면 설치 창의 오류 메시지만 알려 주세요. 키는 보여주지 않습니다.

이미 Python을 설치하셨으므로 실행기가 `py` 또는 `python` 명령을 사용해 가상환경을 만듭니다. Python 3.11 이상이 필요합니다. 실행기는 시스템의 TLS 검증·네트워크 설정을 끄거나 변경하지 않습니다. 자동 테스트에 실패하면 실제 API 수집을 시작하지 않습니다.

## 키와 결과 파일

새로 입력하는 키는 이 실행 프로세스의 환경변수로만 설정합니다. 원래 PC에 있던 사용자 환경변수를 지우거나 덮어쓰지 않습니다. 입력한 키를 로그·ZIP·소스 파일에 기록하지 않습니다. 프로그램 종료 후 새로 입력한 키는 프로세스에서 제거합니다.

기술 진단 ZIP은 로그와 상태 CSV만 포함합니다. 관리자 캐시·원본 엑셀·원문 ZIP은 포함하지 않습니다. 원문은 PC의 `cache/raw/`에 그대로 남습니다. 후속 검수에 필요한 특정 원문은 별도로 확인합니다. 이 기술 진단 ZIP은 Claude 투자 평가용 자료팩이 아닙니다.

다운로드가 되더라도 과거 기업 동일성·정정 관계·당시 문서 버전을 입증하지 못하면 `REVIEW_REQUIRED`로 남습니다. 이는 수집기의 보수적 처리이며, 다운로드 성공을 역사적 검증 성공으로 보고하지 않습니다.

실행기의 비밀 입력·진단 포장·실패 시 중단 로직은 Linux에서 가짜 입력으로 테스트했습니다. Windows `.bat`와 실제 PC 네트워크 실행 결과는 이 시험을 통해 확인해야 합니다.
